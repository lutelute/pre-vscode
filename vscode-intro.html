Point
VS Code は「エディタの軽さ」と「IDEの機能」のバランスが最も良い。拡張機能で自分に必要な機能だけ追加できる。

インストール方法

🍎 macOS

# Homebrew で一発
brew install --cask visual-studio-code

# または公式サイトからダウンロード

🐧 Linux (Ubuntu)

# Snap で一発

sudo apt install code

winget install Microsoft.VisualStudioCode

拡張機能のインストール方法

1

サイドバーから

Extensions アイコン or Cmd + Shift + X

2

検索して Install

拡張機能名を入力 → Install ボタン

3

コマンドラインから

code --install-extension ms-python.python
code --install-extension ms-python.pylance

Tips

  • 拡張機能の入れすぎは起動が遅くなる
  • 不要な拡張機能は無効化でなくアンインストール
  • ワークスペースごとに推奨拡張機能を設定:
    .vscode/extensions.json
{
  "recommendations": [
    "ms-python.python",
    "charliermarsh.ruff"
  ]
}

print() デバッグ vs ビジュアルデバッグ

print() デバッグ

  • コードの書き換えが必要
  • 後で消し忘れるリスク
  • 実行するまで値がわからない
  • 条件付き確認が面倒
  • 途中で止められない
  • 再実行のたびに時間がかかる

VS Code デバッガ

  • コードを変更せずに変数を確認
  • 実行中に値を変更して再開
  • 条件付きブレークポイント
  • コールスタックの確認
  • Watch 式で複雑な式を監視
  • Debug Console で式を評価
実践的なアドバイス
簡単な確認は print() でOK。ループのバグや複雑なロジックの追跡にはデバッガが圧倒的に効率的。

      "program": "${file}",
      "console": "integratedTerminal",
      "justMyCode": true

      "name": "Python: Flask",
      "type": "debugpy",
      "request": "launch",
      "module": "flask",
      "env": { "FLASK_APP": "app.py" },
      "args": ["run", "--debug"]
    }
  ]
}

設定 & カスタマイズ

自分だけの開発環境を作る

おすすめの設定

// settings.json
// Cmd+Shift+P → "Open User Settings (JSON)"
{
  // 自動保存（フォーカスが外れたら保存）
  "files.autoSave": "onFocusChange",

  // 保存時にフォーマット
  "editor.formatOnSave": true,

  // フォントサイズ
  "editor.fontSize": 14,

  // ミニマップ非表示（画面を広く）
  "editor.minimap.enabled": false,

  // 括弧のペアを色分け
  "editor.bracketPairColorization.enabled": true,

  // 末尾の空白を自動削除
  "files.trimTrailingWhitespace": true,

  // 最終行に改行を自動追加
  "files.insertFinalNewline": true,

  // Python のデフォルトインタープリタ
  "python.defaultInterpreterPath": "python3"
}

設定の2つのレベル

  • User 設定: 全プロジェクトに適用
  • Workspace 設定: プロジェクトごと
    .vscode/settings.json

Workspace 設定が User 設定より優先される

生産性を高めるテクニック

Zen Mode

Cmd+K Z でフルスクリーン集中モード。UI が全て消えてコードだけに。Esc×2 で戻る。

Sticky Scroll

スクロール時にスコープ（関数名・クラス名）がエディタ上部に固定表示。今どこにいるか一目瞭然。

Timeline View

Explorer の下部にファイルの変更履歴を時系列で表示。Git コミットやローカルの保存履歴を確認。

Breadcrumbs

エディタ上部にファイルパスとシンボルを表示。クリックで素早くナビゲーション。

Outline View

サイドバーにファイル内の関数・クラス一覧を表示。大きなファイルの構造把握に便利。

Quick Fix

Cmd + . で自動修正提案。インポート追加、変数リネーム、コード修正など。
