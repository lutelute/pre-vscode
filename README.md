## PWS Lab Python Pack (Extension Pack)

プレゼンで紹介する12個の拡張機能をワンクリックでインストール。

```bash
# .vsix から直接インストール
code --install-extension extension/pws-lab-python-pack-1.0.0.vsix
```

含まれる拡張機能: Python, Pylance, Debugpy, Ruff, Jupyter, autoDocstring, GitLens, Remote-SSH, Error Lens, indent-rainbow, Path Intellisense, Japanese Language Pack

詳細は [extension/README.md](extension/README.md) を参照。

## 技術スタック

- `terminal-slide` HTMLフォーマット準拠
- VS Code風UIシェル（タイトルバー / Activity Bar / タブ / ステータスバー）
- GIFデモ: Playwright + ffmpeg（コマンドパレット / マルチカーソル / デバッガ）
- GitHub Pages で自動デプロイ
- `#slide-N` ハッシュによるスライド直接リンク

## ファイル構成

```
pre-vscode/
  index.html              # GitHub Pages エントリ
  vscode-intro.html       # メインプレゼン（44スライド）
  assets/
    command-palette.gif    # コマンドパレットデモ
    multi-cursor.gif       # マルチカーソルデモ
    debugger.gif           # デバッガデモ
  extension/
    package.json           # Extension Pack 定義
    icon.png               # マーケットプレイス用アイコン
    README.md              # 拡張パック説明
    *.vsix                 # パッケージ済みファイル
  gif-src/                 # GIF生成用ソース
  .github/workflows/
    pages.yml              # GitHub Pages デプロイ
```

## ローカルでの表示

```bash
terminal-slide vscode-intro.html
# または
open vscode-intro.html
```

## GIF の再生成

```bash
npm install
node gif-src/capture.mjs
```
