## 全15回 カリキュラム

### 第1回: VS Code とは — エディタの選び方
- VS Code の特徴と他エディタ（Vim, PyCharm, Jupyter）との比較
- インストール方法（macOS / Windows / Linux）
- 初期設定と日本語化

### 第2回: 画面構成編 — UIを理解する
- Activity Bar / Side Bar / Editor / Panel / Status Bar
- ワークスペースとフォルダの概念
- `code` コマンドによるターミナルからの起動

### 第3回: コマンドパレット編 — 全ての操作の入口
- `Cmd+Shift+P` でコマンドパレットを開く
- プレフィックス使い分け（`>`, `@`, `#`, `:`, なし）
- `Cmd+P` によるファイル検索とあいまいマッチ

### 第4回: ショートカット編 — マウスに頼らない操作
- 必須ショートカット12選
- 行操作（移動・複製・削除・コメント切替）
- ファイル操作（開く・閉じる・保存・分割）

### 第5回: マルチカーソル編 — 一括編集の技術
- `Cmd+D` による同一単語の追加選択
- `Alt+Click` / `Cmd+Alt+上下` でカーソル追加
- 実践: 変数リネーム、CSV編集、HTML一括変更

### 第6回: 検索・置換編 — プロジェクト横断の検索力
- ファイル内検索 / プロジェクト全体検索
- 正規表現の活用 / ファイルフィルタ

### 第7回: 拡張機能編 — エコシステムを使いこなす
- Python 開発必須6選 + 汎用おすすめ6選
- `.vscode/extensions.json` による推奨拡張の共有

### 第8回: 統合ターミナル編 — エディタ内で完結する開発
- ターミナルの表示・作成・分割
- エラー出力からのファイルジャンプ

### 第9回: Git 連携編 — GUIでバージョン管理
- Source Control パネル / diff / ブランチ操作
- Merge Conflict の解消 / GitLens

### 第10回: Remote SSH 編 — サーバーで開発する
- SSH config 設定 / 研究室サーバーへの接続
- リモートでの拡張機能 / デバッグ

### 第11回: デバッグ編 — print文からの卒業
- ブレークポイント / ステップ実行
- `launch.json` / 条件付きブレークポイント

### 第12回: 設定・カスタマイズ編 — 自分だけの環境を作る
- User Settings vs Workspace Settings
- テーマ / フォント / キーバインド

### 第13回: Workspace 活用編 — チーム開発の基盤
- `.vscode/` ディレクトリ / スニペット / タスク自動化

### 第14回: AI 支援 & 生産性編 — 最新ツールを活用する
- GitHub Copilot / Continue / Zen Mode / Quick Fix

### 第15回: 総合演習 & Tips 編 — 実践力を鍛える
- 実践課題 / トラブルシューティング / Q&A

## PWS Lab Python Pack (Extension Pack)

プレゼンで紹介する12個の拡張機能をワンクリックでインストール。

```bash
# .vsix から直接インストール
code --install-extension extension/pws-lab-python-pack-1.0.0.vsix
```

含まれる拡張機能: Python, Pylance, Debugpy, Ruff, Jupyter, autoDocstring, GitLens, Remote-SSH, Error Lens, indent-rainbow, Path Intellisense, Japanese Language Pack

詳細は [extension/README.md](extension/README.md) を参照。

## 技術スタック

- `terminal-slide` HTMLフォーマット準拠
- VS Code風UIシェル（タイトルバー / Activity Bar / タブ / ステータスバー）
- GIFデモ: Playwright + ffmpeg（コマンドパレット / マルチカーソル / デバッガ）
- GitHub Pages で自動デプロイ
- `#slide-N` ハッシュによるスライド直接リンク

## ファイル構成

```
pre-vscode/
  index.html              # GitHub Pages エントリ
  vscode-intro.html       # メインプレゼン（44スライド）
  assets/
    command-palette.gif    # コマンドパレットデモ
    multi-cursor.gif       # マルチカーソルデモ
    debugger.gif           # デバッガデモ
  extension/
    package.json           # Extension Pack 定義
    icon.png               # マーケットプレイス用アイコン
    README.md              # 拡張パック説明
    *.vsix                 # パッケージ済みファイル
  gif-src/                 # GIF生成用ソース
  .github/workflows/
    pages.yml              # GitHub Pages デプロイ
```

## ローカルでの表示

```bash
terminal-slide vscode-intro.html
# または
open vscode-intro.html
```

```bash
npm install

```
