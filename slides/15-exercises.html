Step 3: コードを書く (todo.py)

HANDS-ON

todo.py
class TodoList:
    def __init__(self):
        self.tasks = []
    def add(self, task: str) -> None:
        self.tasks.append({"text": task, "done": False})
    def complete(self, index: int) -> None:
        self.tasks[index]["done"] = True
    def remove(self, index: int) -> None:
        del self.tasks[index]
    def pending(self) -> list:
        return [t for t in self.tasks if not t["done"]]
if __name__ == "__main__":
    todo = TodoList()
    todo.add("VS Code を学ぶ")
    todo.add("Python でプロジェクトを作る")
    todo.complete(0)
    print(f"残タスク: {len(todo.pending())}")

Step 4: デバッグで動作確認

HANDS-ON

ブレークポイントを設置

Watch 式を追加

  4. Debug Console で todo.tasks を入力

Step 5: テストを書いて実行

HANDS-ON

test_todo.py
from todo import TodoList
def test_add():
    t = TodoList()
    t.add("task1")
    assert len(t.tasks) == 1
    assert t.tasks[0]["text"] == "task1"
def test_complete():
    t = TodoList()
    t.add("task1")
    t.complete(0)
    assert t.tasks[0]["done"] is True
def test_pending():
    t = TodoList()
    t.add("task1")
    t.add("task2")
    t.complete(0)
    assert len(t.pending()) == 1

トラブルシューティングガイド

問題原因解決策
拡張機能が動かないWorkspace Trust が制限モード左下の "Restricted Mode" → Trust
Python が見つからないインタプリタ未選択Cmd+Shift+P → Select Interpreter
Git が検出されないGit 未インストール or PATHgit --version で確認。Xcode CLT
Remote SSH 接続失敗SSH設定・鍵のミス~/.ssh/config と鍵の権限確認
ターミナルが遅いシェル起動ファイルが重い.zshrc を軽量化、不要プラグイン削除
formatOnSave が動かないフォーマッタ未設定defaultFormatter を設定

トラブルシューティング (続き)

問題原因解決策
VS Code が重い拡張機能が多すぎ不要な拡張を無効化。Profiles で分離
検索結果が多すぎnode_modules等を含む"search.exclude" で除外設定
日本語入力が変IME との干渉"editor.suggest.snippetsPreventQuickSuggestions": false
デバッグが始まらないdebugpy 未インストールPython Debugger 拡張をインストール
Copilot が動かない認証切れ or 制限超過ステータスバーの Copilot アイコン確認

困ったら: Cmd+Shift+P → "Developer: Reload Window" で再読み込み

パフォーマンスTips

拡張機能の管理

  • 使わない拡張は無効化（削除不要）
  • Workspace 単位で有効/無効を切替
  • Profiles で用途別に分離
  • @installed で全拡張を確認

ファイル監視の除外

"files.watcherExclude": {
  "**/node_modules": true,
  "**/.git": true,
  "**/venv": true,
  "**/__pycache__": true
}

大きなフォルダを監視対象から除外してパフォーマンスUP。
