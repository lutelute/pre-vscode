実践課題: Pythonプロジェクト作成

CHALLENGE

課題（30分）

以下の手順で Python プロジェクトを一から作成してください。

  1. mkdir ~/final-project && cd ~/final-project && code .
  2. python -m venv .venv && source .venv/bin/activate
  3. .vscode/settings.json を作成（autoSave, formatOnSave）
  4. main.py に簡単な計算プログラムを作成
  5. utils.py にヘルパー関数を作成
  6. git init → Stage → Commit
  7. ブレークポイントを設定して F5 でデバッグ
  8. マルチカーソルで変数名を一括変更

実践課題: チェックポイント

確認項目

☐フォルダを code . で開けた☐仮想環境が有効化されている（ステータスバー確認）☐.vscode/settings.json が作成済み☐Pythonスクリプトが実行できる☐Git で最初のコミットが完了☐デバッガでブレークポイントが動作☐マルチカーソルで変数名変更ができた☐Cmd+P でファイル間ジャンプができた

トラブルシューティング

Python が認識されない

→ Cmd+Shift+P → "Python: Select Interpreter" でPythonパスを指定

拡張機能が動かない

→ Cmd+Shift+P → "Developer: Reload Window" で再読み込み

Remote-SSH で接続できない

→ ssh -v host でターミナルから接続テスト。鍵のパーミッション確認 (chmod 600)

VS Code が重い

→ 不要な拡張を無効化。Cmd+Shift+P → "Developer: Open Process Explorer" でCPU使用を確認

トラブルシューティング（つづき）

フォーマットが効かない

→ "editor.defaultFormatter" を確認。Ruff の場合: "charliermarsh.ruff"

Git の変更が表示されない

→ フォルダを開き直す。git status でリポジトリが初期化されているか確認

デバッグが動かない

→ Python 拡張が最新版か確認。launch.json を再作成 (Run → Add Configuration)

5つの重要ポイント

1. フォルダで開く

code . が全ての始まり。ファイル単体NG。

2. コマンドパレット
