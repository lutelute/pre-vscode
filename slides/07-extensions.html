Python必須拡張 1/6: Python

Py

Python by Microsoft

Python言語の基盤拡張。IntelliSense、デバッグ、テスト、環境管理を提供。

DL: 120M+ | Rating: 4.5/5

提供される機能

  • Python インタープリタの選択
  • コード実行 (Run Python File)
  • デバッグ統合
  • 仮想環境の自動検出
  • テストフレームワーク統合

インタープリタ選択

Cmd+Shift+P → Python: Select Interpreter

venv, conda, pyenv 等を自動検出。プロジェクトごとに切り替え可能。

Python必須拡張 2/6: Pylance

Pl

Pylance by Microsoft

超高速な Python Language Server。型チェック、自動補完、リファクタリングを強化。

DL: 80M+ | Rating: 4.3/5

主な機能

  • 高精度な自動補完（型推論）
  • 型エラーのリアルタイム検出
  • 自動 import
  • Go to Definition / References
  • コードアクション（Quick Fix）

型チェックモード

settings.json:

"python.analysis.typeCheckingMode":
  "basic" // off | basic | strict

Python必須拡張 3/6: Ruff

Rf

Ruff by Astral Software

Rust製の超高速リンター＆フォーマッター。flake8 + black + isort を1つで置き換え。

DL: 10M+ | Rating: 4.8/5

特徴

  • flake8 の10〜100倍高速
  • 800+ のルールに対応
  • 保存時に自動フォーマット
  • import の自動ソート
  • pyproject.toml で設定

推奨設定

// settings.json
"editor.formatOnSave": true,
"editor.defaultFormatter":
  "charliermarsh.ruff",
"editor.codeActionsOnSave": {
  "source.organizeImports":
    "explicit"
}

Python必須拡張 4/6: Jupyter

Jp

Jupyter by Microsoft

VS Code内でJupyter Notebookを編集・実行。.ipynb をネイティブサポート。

DL: 70M+ | Rating: 4.2/5

できること

  • .ipynb ファイルの編集・実行
  • セル単位のコード実行
  • グラフ・画像のインライン表示
  • 変数エクスプローラ
  • Markdown セルのプレビュー

Interactive Window

.py ファイルに # %% でセル区切りを書くと、Notebook風に実行できる。

Shift+Enter でセルを実行

Python必須拡張 5/6: Python Debugger (debugpy)

Db

Python Debugger by Microsoft

Pythonのデバッグ実行を提供。ブレークポイント、ステップ実行、変数監視。

DL: 30M+ | Python拡張に含まれる場合あり

デバッグ機能

  • ブレークポイント設定
  • ステップ実行 (Over/Into/Out)
  • 変数の値をホバーで確認
  • Watch 式の追加
  • Call Stack の確認

始め方

1. 行番号の左をクリック → 赤い丸

2. F5 でデバッグ開始

3. ブレークポイントで停止

4. F10 でステップ実行

Python必須拡張 6/6: autoDocstring

Do

autoDocstring by Nils Werner

関数定義の下で """ と入力すると、引数・戻り値のdocstringを自動生成。

DL: 5M+ | Rating: 4.5/5

Before

def calculate(price, tax):
    """ ← ここでEnter

After (自動生成)

def calculate(price, tax):
    """Summary

    Args:
        price: Description
        tax: Description
    """

インストール方法

方法1: サイドバー

1. Cmd+Shift+X

2. 拡張名で検索

3. 「Install」をクリック

最も一般的な方法

方法2: CLI

$ code --install-extension
  ms-python.python

スクリプトで一括インストール可能

方法3: VSIX ファイル

1. .vsix ファイルを入手

2. code --install-extension file.vsix

拡張機能の管理

有効/無効の切り替え

拡張パネルで歯車 → 「Disable」

ワークスペース単位で切り替え可能

アンインストール

拡張パネルで「Uninstall」

CLI: code --uninstall-extension ID

自動更新

デフォルトON。手動更新に変更可。

"extensions.autoUpdate": false

一覧表示 (CLI)

code --list-extensions

インストール済みIDが出る

extensions.json でチーム共有

推奨拡張をプロジェクトに記録

// .vscode/extensions.json
{
  "recommendations": [
    "ms-python.python",
    "ms-python.vscode-pylance",
    "charliermarsh.ruff",
    "usernamehw.errorlens"
  ]
}

効果: プロジェクトを開くと「推奨拡張があります」と通知。Gitにコミットしてチーム全員が同じ環境に。

良い拡張の見分け方

良いサイン

  • ダウンロード数 100K+
  • 最近も更新されている
  • 評価 4.0 以上
  • Microsoft/有名企業が開発
  • GitHubリポジトリがアクティブ

注意サイン

  • 最終更新が1年以上前
  • ダウンロード数 1K 未満
  • 評価 3.0 未満
  • Issue が大量に未対応
  • 似た名前の偽拡張に注意

拡張機能のトラブル

拡張同士の競合

同じ機能の拡張を複数入れると衝突。例: 複数のFormatter。

対策: "editor.defaultFormatter" で明示指定

パフォーマンス低下

拡張を入れすぎるとVS Codeが遅くなる。

対策: Developer: Show Running Extensions で重い拡張を特定

拡張が壊れた場合

VS Codeが起動しない・クラッシュする。

対策: code --disable-extensions で起動 → 原因特定
