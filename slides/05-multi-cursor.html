app.py — マルチカーソル例
def calculate_total(price, tax):
total = price + (price * tax)
return total

手順: price をダブルクリックで選択 → Cmd+D を2回押す → 3つの price が全て選択される → unit_price と入力 → 全て一括変更！

Cmd+D の便利なTips

スキップ: Cmd+K, Cmd+D

今の選択をスキップして次のマッチへ飛ぶ。

例: 3つ目の name だけ変えたくない場合に使う

元に戻す: Cmd+U

最後に追加したカーソル/選択を1つ取り消す。

Cmd+D を押しすぎたときに使う

大文字/小文字の区別

Cmd+D は大文字小文字を区別してマッチする。

Name と name は別扱い。正確にリネームできる

Cmd+D 実例: 変数リネーム

models.py
class User:
def __init__(self, username, email):
self.username = username
self.email = email
def display(self):
return f"User: {self.username}"

username を選択 → Cmd+D ×3 → 4箇所同時選択 → user_name と入力

注意: F2 (Rename Symbol) との違い — F2はインポート先も含めて変更。Cmd+D はファイル内のみ

よくある失敗と対処法

失敗1: 意図しない場所もマッチした

Cmd+Shift+L で全選択したら、コメント内の同名変数も変更してしまった

対処: Cmd+Z で元に戻し、Cmd+D で1つずつ確認しながら選択

失敗2: マルチカーソルが残ったまま入力

カーソルが複数あることに気づかず、別の場所にも文字が入ってしまった

対処: Esc を押してからCmd+Z。ステータスバーに「カーソル: N個」と表示される

失敗3: 部分一致でマッチしすぎ

id を選択したら width, hidden の中の id もマッチ

対処: 検索ダイアログの「単語単位」オプションをON にしてから Cmd+Shift+L

マルチカーソル + 他機能の組み合わせ

+ 行選択

マルチカーソル中に Cmd+L で複数行を一括選択

+ Home/End

全カーソルが一斉に行頭/行末に移動

+ 単語選択

Cmd+Shift+→ で全カーソル位置の単語を選択

+ コピー＆ペースト

N個のカーソルでコピーした内容は、N個のカーソルに1行ずつ分配される

+ インデント

Tab / Shift+Tab で複数行同時インデント

+ 削除

Backspace / Delete で全カーソル位置を同時削除

マルチカーソルとコピー＆ペーストの特殊動作

ケース1: N行コピー → N個のカーソルにペースト

コピー元（3行）:
alpha
beta
gamma

3個のカーソルでペースト:
カーソル1 → alpha
カーソル2 → beta
カーソル3 → gamma

ケース2: 1行コピー → N個のカーソルにペースト

コピー元（1つ）:
prefix_

3個のカーソルでペースト:
カーソル1 → prefix_
カーソル2 → prefix_
カーソル3 → prefix_

マルチカーソルを使わないほうがいい場面

プロジェクト全体のリネーム

複数ファイルにまたがる変更は F2（Rename Symbol）を使う。

マルチカーソルは1ファイル内でしか動作しない

複雑なパターンの置換

正規表現が必要な変換は Cmd+H（検索・置換）を使う。

例: 日付形式の変換 (2024-01-15 → 01/15/2024)

各行で異なる内容を入力

マルチカーソルは全カーソルに同じ入力をする。行ごとに違う内容は1行ずつ。

ただしコピー＆ペーストの分配機能は活用できる

まとめ

Cmd+D

同じ単語を1つずつ選択。最も使用頻度が高い。スキップも可能。

Alt+Click

任意の位置にカーソルを追加。バラバラな場所の編集に。

Cmd+Alt+Arrow

上下にカーソルを追加。連続行の編集に最適。

Cmd+Shift+L

全出現箇所を一括選択。確実に全部変えたいとき。

矩形選択

Shift+Alt+ドラッグで列方向のブロック選択。

Esc で解除

マルチカーソルを安全に終了。ステータスバーで確認。
