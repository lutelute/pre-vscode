マルチカーソルとは

同時に複数の場所を編集する機能

10箇所の変数名を変えるのに、10回コピペ？
マルチカーソルなら1回で完了。

GIF デモ

複数箇所を同時編集している様子

方法1: Cmd+D（同じ単語を順次選択）

使い方

  1. 変更したい単語にカーソルを置く
  2. Cmd+D を押すたびに次の同じ単語が選択される
  3. そのまま入力すると全箇所が同時に変わる

Tips

  • Cmd+D を押しすぎたら Cmd+U で1つ戻る
  • スキップしたい場合は Cmd+K Cmd+D
  • 全ての同じ単語を一括選択: Cmd+Shift+L

方法2: Alt+Click（任意の位置にカーソル追加）

使い方

Alt (macOS: Option) を押しながらクリックすると、クリックした場所にカーソルが追加される。

使いどころ

  • 離れた場所に同時にテキストを追加したい時
  • リストの各行の先頭に記号を追加
  • 不規則な位置の編集

方法3: Cmd+Alt+↑↓（上下にカーソル追加）

連続した行に一括カーソル

Cmd+Alt+↑ or Cmd+Alt+↓ で上下の行にカーソルを追加。
Windows/Linux: Ctrl+Alt+↑↓

Before

name = "Alice"
age = 25
city = "Tokyo"
job = "Engineer"

After (先頭にself.を追加)

self.name = "Alice"
self.age = 25
self.city = "Tokyo"
self.job = "Engineer"

方法4: Cmd+Shift+L（全一致選択）

ファイル内の全ての同じ単語を一括選択

  1. 変更したい単語を選択（ダブルクリック or Cmd+D）
  2. Cmd+Shift+L で全一致を選択
  3. 入力すると全箇所が同時に変更される

Cmd+D vs Cmd+Shift+L

Cmd+DCmd+Shift+L
選択1つずつ順番に全部一括
スキップ可能（Cmd+K Cmd+D）不可
用途部分的な変更全置換

矩形選択（Box Selection）

Shift+Alt+ドラッグ

矩形（四角形）の範囲を選択。CSV やテーブルデータの列操作に便利。

例: CSVの特定列だけ選択

Alice,25,Tokyo
Bob,30,Osaka
Carol,22,Kyoto
Dave,28,Nagoya

年齢の列だけ選択して一括操作

実践例1: 変数リネーム

Before

data = load_csv()
clean_data = preprocess(data)
result = analyze(clean_data)
save(result, data)

After (Cmd+D で data → df)

df = load_csv()
clean_df = preprocess(df)
result = analyze(clean_df)
save(result, df)

より安全なリネーム: F2（Rename Symbol）を使うと参照を追跡してリネーム

実践例2: HTMLタグ一括変更

Before

<div>Item 1</div>
<div>Item 2</div>
<div>Item 3</div>

After (div → li に一括変更)

<li>Item 1</li>
<li>Item 2</li>
<li>Item 3</li>

マルチカーソル演習（15分）

  1. Pythonファイルで変数 data を10箇所書く
  2. Cmd+D で1つずつ選択して df に変更
  3. 新しいファイルでリスト項目を5行書く
  4. Cmd+Alt+↓ で全行にカーソルを置き、先頭に - を追加
  5. CSVデータを作成し、矩形選択で列を選択
  6. Cmd+Shift+L で全置換を試す

まとめ

Cmd+D が最重要

同じ単語を順次選択。90%のマルチカーソル操作はこれで足りる。

4つの方法を使い分ける

Cmd+D / Alt+Click / Cmd+Alt+↑↓ / Cmd+Shift+L を状況に応じて。

Esc で元に戻る

マルチカーソルを解除するには Esc を1回押すだけ。
