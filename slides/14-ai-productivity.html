AIコーディングツールの全体像

GitHub Copilot

Microsoft/GitHub 製。最も普及。VS Code 公式統合。学生無料。インライン補完 + チャット。

Copilot を上手に使うコツ

1. 良いコメント・関数名を書く

Copilot はコンテキストから推測する。意図を明確にするほど良い提案が来る。

2. 小さな関数から始める

1つの関数の補完は高精度。100行の関数を一気に書かせるのは危険。

3. 生成されたコードを必ず読む

Tab で採用する前にコードを理解する。理解できないコードは使わない。

4. テストで検証する

AI生成コードこそテストが重要。/tests で自動生成してカバレッジを確保。

Continue — オープンソースAIアシスタント

特徴

  • オープンソース — コードを確認可能
  • モデル選択 — Claude / GPT / Gemini / Ollama
  • ローカルLLM — データが外に出ない
  • カスタマイズ — プロンプトテンプレート

インストール

  2. インストール

  4. Cmd+L でチャット開始

Copilot の代替として人気上昇中

Cline — 自律型AIエージェント

Cline の特徴

  • ファイルの作成・編集・削除を自律実行
  • ターミナルコマンドの実行
  • ブラウザの操作（スクリーンショット+クリック）
  • MCP (Model Context Protocol) 対応
  • 各操作前に承認を求める（安全性）

使い方

「このプロジェクトにログイン機能を追加して」のような自然言語の指示で、Cline が複数ファイルを編集し、テストを実行し、バグを修正する。

注意: APIコスト（トークン消費）に注意。Claude や GPT のAPIキーが必要。

VS Code フォークだが...

  • Cmd+K でインラインAI編集
  • Cmd+L でコンテキスト付きチャット
  • Codebase全体を理解した提案

AI コーディングの注意点

1. ハルシネーション（幻覚）

存在しないAPIやライブラリ関数を自信満々に提案する。必ず公式ドキュメントで確認。

2. セキュリティリスク

SQLインジェクション・ハードコードされたシークレット等、脆弱なコードを生成する場合がある。

3. コード品質の低下

動くが保守しにくいコードになりがち。コードレビューの目を養うことが重要。

4. 学習の妨げ

理解せずにTabを押し続けると成長しない。「なぜこのコードか」を常に考える。

Zen Mode — 集中モード

Cmd+K Z (Mac) / Ctrl+K Z (Win/Linux)

全画面表示 + サイドバー・ステータスバー・タブが全て非表示。
Esc を2回押しで元に戻る。

通常モード

サイドバー、タブ、ステータスバー、ミニマップ... 情報過多で気が散る。

Zen Mode

コードだけ。集中してコーディングしたい時に最適。プレゼン時にも使える。

Sticky Scroll — スコープヘッダー固定

class UserService: ← 固定!
def get_user(self, id): ← 固定!
        # ここまでスクロールしても

"editor.stickyScroll.enabled":
  true

長い関数やクラスをスクロールしても、「今どのスコープにいるか」が常にわかる。デフォルトON。

Breadcrumbs — ファイルパスナビゲーション

src / services / user_service.py / UserService / get_user

エディタ上部に表示されるパンくずリスト

機能

  • ファイルパス + シンボル（関数/クラス）を表示
  • クリックでファイル/シンボルの一覧
  • 別のファイルへ素早くジャンプ

ショートカット

Cmd+Shift+. で Breadcrumbs にフォーカス。
矢印キーで移動、Enter で選択。

設定: "breadcrumbs.enabled": true

Outline — 関数/クラスの目次

OUTLINE — user_service.py
▼ UserService class
  __init__ method
  get_user method
  create_user method
  update_user method
  delete_user method
▼ UserValidator class
  validate_email method
  validate_name method

使い方

Explorer の下部にある "OUTLINE" セクション。または:

Cmd+Shift+O でファイル内シンボル検索（同等機能）。

クリックで該当箇所にジャンプ。長いファイルの全体把握に最適。

Quick Fix — 即座に問題を解決

Cmd+. (Mac) / Ctrl+. (Win/Linux)

黄色い電球マークが表示されたら Quick Fix が利用可能

自動インポート

未インポートのモジュールを使用 → Quick Fix で import 文を自動追加。

変数名修正

タイポ検出 → 正しい名前の候補を提案。F2 でリネームリファクタリング。

未使用インポートの削除

使っていない import を検出して「Remove unused import」を提案。

型の追加

Pylance が型を推論して「Add type annotation」を提案。
