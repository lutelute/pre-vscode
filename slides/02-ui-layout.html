5つのエリア一覧

1. Activity Bar（左端）

アイコンバー。Explorer, Search, Git, Debug, Extensions を切り替える。サイドバーの「リモコン」。

2. Side Bar（左パネル）

Activity Barで選んだビューが表示される。ファイルツリー、検索結果、Git変更など。

3. Editor Group（中央）

コードを編集するメイン領域。タブ、分割、グリッドレイアウトに対応。

4. Panel（下部）

Terminal, Problems, Output, Debug Console。コード実行とエラー確認。

5. Status Bar（最下部）

ブランチ名、エラー数、文字コード、言語モード、行・列番号。クリックで設定変更可能。

Open Folder が重要な5つの理由

1. IntelliSense が正しく動く

import文の解決にはプロジェクトルートが必要。単体ファイルだと補完が効かない。

2. Git が使える

.git がプロジェクトルートにある。Source Control パネルが機能する。

3. プロジェクト全文検索

Cmd+Shift+F でプロジェクト内を横断検索。

4. .vscode/ 設定が読み込まれる

launch.json（デバッグ）、settings.json（プロジェクト設定）が有効に。

5. 拡張機能がフル機能で動作

Linter、Formatter、Test Runnerはプロジェクトルートを基準に設定を読む。

Remote SSH の注意点

危険: ホームディレクトリを開く

# これはやってはいけない:
$ code --remote ssh-remote+server /home/user
# ホームディレクトリ全体をインデックス → サーバー負荷大

CPUとメモリを圧迫し、他のユーザーに迷惑をかける

正解: プロジェクトフォルダを開く

# プロジェクトフォルダを指定:
$ code --remote ssh-remote+server /home/user/my-project

必要なフォルダだけを開く。軽量で安全。
