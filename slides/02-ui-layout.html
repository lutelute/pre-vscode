Side Bar — Explorer の活用

Explorer ビュー

  • ファイルツリー: フォルダ構造を表示
  • 新規作成: ファイル/フォルダアイコンをクリック
  • ドラッグ&ドロップ: ファイル移動
  • 右クリック: リネーム、削除、パスコピー

Outline ビュー

  • 関数・クラスの一覧を表示
  • クリックで該当箇所にジャンプ
  • 大きなファイルの構造把握に便利

Timeline ビュー

  • ファイルの変更履歴を時系列表示
  • Git commit ごとの差分も確認可能

Open Folder vs Open File

Open File（NG）

  • ファイル1つだけ開く
  • Explorer にファイルツリーなし
  • プロジェクト横断検索不可
  • Git統合が使えない
  • .vscode/settings.json が効かない
  • 拡張機能の動作が制限される

Open Folder（推奨）

  • プロジェクト全体を認識
  • ファイルツリーが表示される
  • Cmd+Shift+F で全文検索
  • Git差分・コミットがGUIで
  • ワークスペース設定が有効
  • 全拡張機能がフル機能動作

鉄則: code . でフォルダごと開く！

files.exclude / search.exclude

files.exclude

Explorer に表示したくないファイル/フォルダを隠す設定

settings.json
// settings.json
{
  "files.exclude": {
    "**/__pycache__": true,
    "**/*.pyc": true,
    "**/.DS_Store": true
  }
}

search.exclude

検索対象から除外。files.exclude に加えて検索専用の除外を追加。

例: "search.exclude": { "**/node_modules": true, "**/venv": true }

やってはいけないこと 6選（前半）

NG 1: ホームディレクトリを開く

code ~ は絶対NG！ 数万ファイルをインデックスしてVS Code が固まる。
必ずプロジェクトフォルダ（例: ~/projects/my-app）を開くこと。

NG 2: ファイルをドラッグ&ドロップで開く

ファイル単体が開かれ、フォルダとして認識されない。
→「Open Folder」or code . を使おう。

NG 3: 自動保存を無効のまま使う

保存忘れで「動かない！」というトラブルが頻発。
→ "files.autoSave": "afterDelay" を設定しよう。

やってはいけないこと 6選（後半）

NG 4: 拡張機能を入れすぎる

必要のない拡張を大量に入れると重くなる。
→ Session 07 で厳選したものだけ入れよう。

NG 5: ショートカットを全く使わない

マウスだけで操作すると、プロの10倍遅い。
→ 毎日2-3個ずつ覚えよう（Session 04 で解説）。

NG 6: 設定を一切カスタマイズしない

デフォルト設定は万人向け。自分に合わせると効率UP。
→ Session 12 で推奨設定を紹介。

Breadcrumbs（パンくずリスト）

my-project  /  src  /  utils.py  /  calculate_score

エディタ上部に表示されるファイルパスと構造のナビゲーション。

  • 各要素をクリックすると同階層のファイル/シンボルが表示される
  • 深いフォルダ構造でも現在位置がすぐわかる
  • Cmd+Shift+. でフォーカス → ↑↓で移動

有効化

"breadcrumbs.enabled": true（デフォルトでON）

集中モード

Zen Mode

Cmd+K Z

全てのUI要素を隠してエディタだけの全画面表示。
論文執筆やコーディングに集中したい時に。
Esc Esc で解除。

Full Screen

Ctrl+Cmd+F

通常のフルスクリーン。
サイドバーやパネルは表示されたまま。
プレゼンテーション時にも便利。

Workspace Trust（補足）

信頼されたフォルダ

初めてフォルダを開くと「このフォルダの作成者を信頼しますか？」と聞かれることがある。

自分のプロジェクトなら「Trust」でOK。

Restricted Mode だと何が起きる？

  • 拡張機能が一部動作しない
  • デバッグが無効
  • タスク実行が制限される

不審なリポジトリを開く時のセキュリティ機能。自分のコードなら常に Trust。

まとめ

5つの領域を理解する

Activity Bar → Side Bar → Editor → Panel → Status Bar

Open Folder が鉄則

ファイル単体ではなく code . でフォルダごと開く。ホーム直下はNG。

レイアウトは自在に変更可能

Cmd+B, Cmd+J, Cmd+\ で表示切替・分割。

autoSave を早めに設定

保存忘れトラブルを防ぐ。"files.autoSave": "afterDelay"
