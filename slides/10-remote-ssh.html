VS Code のUIだけローカルで動作。ファイル操作、ターミナル、拡張機能は全てサーバー上で実行。
まるでサーバーの前に座っているかのような体験。

SSH Config 設定

~/.ssh/config
# PWS Lab サーバー設定
Host pws-160core
  HostName 100.104.225.55
  User pws-ubuntu-server
  IdentityFile ~/.ssh/id_ed25519
Host pws-gpu
  HostName 100.126.144.110
  User root
  IdentityFile ~/.ssh/id_ed25519

SSH鍵を設定しておくとパスワード不要で接続: ssh-keygen -t ed25519 → ssh-copy-id

接続手順

ステップバイステップ

  1. Remote - SSH 拡張をインストール
  2. Cmd+Shift+P → "Remote-SSH: Connect to Host"
  3. SSH config の Host名を選択（例: pws-160core）
  4. 初回はサーバーに VS Code Server が自動インストール
  5. 接続完了 → "Open Folder" でプロジェクトフォルダを開く

リモートの拡張機能

ローカル vs リモート拡張

種類動作場所例
UI拡張ローカルテーマ、キーマップ
Workspace拡張リモートPython, Pylance, GitLens

リモートにも拡張のインストールが必要

接続後に Cmd+Shift+X で拡張機能ビューを開くと、リモート用のインストールボタンが表示される。

注意事項

NG: ホームディレクトリ直下を開く

/home/username/ を直接開くと、全ファイルがインデックスされて重くなる。
→ 必ずプロジェクトフォルダ（例: ~/projects/my-research）を開く。

注意: ネットワーク切断

VPN/Tailscaleが切れると接続が切断される。ターミナルの長時間処理は tmux か screen で保護。

Tips: ポートフォワーディング

サーバーで起動した Web サーバー (Flask等) のポートが自動的にローカルに転送される。
localhost:5000 でアクセス可能。
