VS Code で最も重要な機能

Cmd+Shift+P

Command Palette

VS Code の全コマンド（2000以上）にアクセスできる唯一の入口。
ショートカットを覚えなくても、コマンドパレットさえ使えれば何でもできる。

メニューを探す時間がゼロになる。
「あの機能どこだっけ?」 → Cmd+Shift+P で検索すれば即発見。

Command Palette の見た目

Format DocumentShift+Alt+F
Format Document With...
Format SelectionCmd+K Cmd+F
Format Modified Lines

タイプするだけでリアルタイムにフィルタリング。
部分一致で検索されるので、正確なコマンド名を覚える必要はない。

「apco」と入力すると「app/config.py」がヒット。
パスの一部、ファイル名の一部、どこにマッチしてもOK。
正確な名前を覚える必要がない。

ファイルナビゲーション

Cmd+P

Quick Open。ファイル名でファジー検索。プロジェクト内の全ファイルが対象。

Ctrl+Tab

最近使ったタブを順に切り替え。Alt+Tab のエディタ版。

Cmd+W

現在のタブを閉じる。

Cmd+Shift+T

閉じたタブを再度開く（ブラウザと同じ）。

Cmd+1/2/3

エディタグループ1/2/3にフォーカスを移動。分割時に便利。

Cmd+\

エディタを縦に分割。コード比較時に重宝。

使い方

Cmd+Shift+O または Cmd+P → @

@: でカテゴリ別に表示（function, class, variable）

@ vs #

@ — 今開いているファイルの中だけ
# — プロジェクト全体を横断検索

Cmd+T で直接アクセス可能。
大規模プロジェクトでクラスや関数を一発で見つける。

Go to Line 42

基本検索

Cmd+Shift+F で検索パネル。プロジェクト全体から文字列を検索。

正規表現

検索バーの .* ボタンで正規表現ON。
def \w+_data で関数名パターンマッチ。

置換

Cmd+Shift+H で検索&置換。プレビュー確認後に一括置換可能。

検索の詳細オプション

大文字小文字区別

検索バーの Aa ボタン。
デフォルトは区別なし。

単語単位マッチ

ab| ボタン。「data」で「database」をヒットさせない。

ファイルフィルタ

「files to include」に *.py と入力するとPythonファイルだけ検索。

除外パターン

「files to exclude」に node_modules,dist で除外。

Tip: ファイル内検索は Cmd+F。プロジェクト検索は Cmd+Shift+F。

まとめ

Cmd+Shift+P = 全機能の入口

2000以上のコマンドにアクセス。メニューを探す必要がなくなる。

5つのプレフィックスを使い分け

> コマンド / (なし) ファイル / @ シンボル / # 全シンボル / : 行番号

Quick Open (Cmd+P) でファジー検索

ファイル名の一部を入力するだけ。正確な名前を覚える必要なし。

F12 / Shift+F12 / Ctrl+- のコンボ

定義へジャンプ → 参照を確認 → 元に戻る。この3手で全体把握。
