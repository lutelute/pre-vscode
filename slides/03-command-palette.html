コマンドパレットとは

Cmd+Shift+P

(Windows/Linux: Ctrl+Shift+P)

VS Code の全ての機能にアクセスできる検索窓

メニューバーを探す必要なし。設定を探す必要なし。
やりたいことを文字で打つだけで見つかる。

デモ：コマンドパレット

Cmd+Shift+P → キーワードを入力 → 候補を選択 → 実行

プレフィックスで絞り込む

プレフィックス起動方法機能例
>Cmd+Shift+Pコマンド実行> Toggle Minimap
なしCmd+Pファイル検索main.py
@Cmd+P → @シンボル検索（現ファイル）@calculate
#Cmd+P → #シンボル検索（全ファイル）#MyClass
:Cmd+P → :行番号ジャンプ:42

Cmd+Shift+P は Cmd+P に > が入った状態と同じ

Cmd+P：ファイル検索

あいまいマッチ（Fuzzy Match）

完全一致しなくてもOK。頭文字や部分文字列で検索できる。

入力: mp → マッチ: main.py
入力: utpy → マッチ: utils.py
入力: tst → マッチ: test_main.py

便利な使い方

  • Cmd+P → ファイル名 → Enter で開く
  • Cmd+P → ファイル名 → Cmd+Enter で横に分割して開く
  • Cmd+P → ファイル名 → → でプレビュー

@：シンボル検索（現在のファイル）

使い方

Cmd+Shift+O または Cmd+P → @ を入力

@: とコロンを付けると、種類別にグルーピングされる

Python での表示例

class DataProcessor
  def __init__
  def load_data
  def process
  def save_results

こんな時に便利

  • 長いファイルで関数を探す
  • クラスのメソッド一覧を見る
  • Outline ビューの代わりに

:（コロン）：行番号ジャンプ

Ctrl+G  or  Cmd+P → :42

エラーメッセージに「line 42」と出たら → Ctrl+G → 42 → Enter

実践例

Terminal
$ python main.py
Traceback (most recent call last):
  File "main.py", line 42, in calculate
TypeError: unsupported operand type(s)
# → Ctrl+G → 42 → Enter でジャンプ！

#：グローバルシンボル検索

プロジェクト全体のシンボルを検索

Cmd+P → # → シンボル名を入力

関数名、クラス名、変数名など — どのファイルにあるか関係なく検索

@ と # の違い

@#
範囲現在のファイルのみプロジェクト全体
速度非常に速いやや遅い（初回）
用途今見ているファイル内を移動「あの関数どこだっけ？」

コマンドパレット vs メニューバー

メニューバーで操作

  1. File メニューを開く
  2. Preferences を探す
  3. Settings をクリック
  4. 検索バーに入力...

4ステップ、5秒以上

コマンドパレットで操作

  1. Cmd+Shift+P
  2. settings と入力
  3. Enter

3ステップ、2秒以下

メニューの場所を覚える必要なし。やりたいことの英語を打つだけ。

設定の検索

GUI設定 vs JSON設定

Cmd+, → GUI設定画面（検索バーで絞り込み）
Cmd+Shift+P → "Open Settings (JSON)" → 直接編集

設定の探し方

  • Cmd+, で設定を開く → 検索バーにキーワード入力
  • 例: 「font size」と入力 → フォントサイズ関連の設定が全て表示
  • 例: 「auto save」と入力 → 自動保存の設定項目が表示
  • 「Modified」フィルタ → 変更済み設定だけ表示
