なぜ統合ターミナルか

外部ターミナル

  • VS Code と別ウィンドウ
  • 画面切り替えが必要
  • ディレクトリが別
  • エラー行へのジャンプ不可

統合ターミナル

  • エディタと同じウィンドウ
  • Ctrl+` で即切替
  • プロジェクトフォルダが自動CWD
  • エラー行をクリックでジャンプ
  • ファイルパスもリンク化

ターミナル設定

settings.json
// ターミナル設定
{
  "terminal.integrated.fontSize": 14,
  "terminal.integrated.scrollback": 10000,
  "terminal.integrated.defaultProfile.osx": "zsh",
  "terminal.integrated.env.osx": {
    "PYTHONDONTWRITEBYTECODE": "1"
  }
}

Python 実行

Terminal
# 仮想環境の作成と有効化
$ python -m venv .venv
$ source .venv/bin/activate
(.venv) $
# パッケージのインストール
(.venv) $ pip install numpy pandas matplotlib
# スクリプト実行
(.venv) $ python main.py
Hello, PWS Lab!

Python インタープリタの選択

VS Code が仮想環境を自動検出

ステータスバーの Python バージョンをクリック → インタープリタ選択
or Cmd+Shift+P → "Python: Select Interpreter"

選択肢

  • .venv/bin/python — プロジェクトの仮想環境
  • /usr/bin/python3 — システムPython
  • conda 環境 — Anaconda使用時

推奨: プロジェクトごとに .venv を作成

エラーリンク

ターミナルのエラーがクリック可能

Terminal
$ python main.py
Traceback (most recent call last):
  File "main.py", line 42
NameError: name 'data' is not defined

main.py:42 を Cmd+Click すると、そのファイルの42行目にジャンプ！

練習タイム

HANDS-ON

ターミナル演習（15分）

  1. Ctrl+` でターミナルを開く
  2. python -m venv .venv && source .venv/bin/activate
  3. ステータスバーで仮想環境のPythonが選択されているか確認
  4. Pythonスクリプトを作成して python main.py で実行
  5. 意図的にエラーを作り、エラーリンクをクリックしてジャンプ
  6. ターミナルを分割して2つ同時に使う

まとめ

Ctrl+` で即アクセス

外部ターミナルは不要。VS Code 内で完結。

エラーリンクが最大の利点

エラーメッセージからワンクリックで該当行にジャンプ。

仮想環境はプロジェクトごとに

python -m venv .venv を習慣にする。
