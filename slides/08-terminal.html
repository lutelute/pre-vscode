なぜ統合ターミナル？

外部ターミナル

  • エディタとターミナルを行き来
  • 作業ディレクトリが別
  • ウィンドウ切り替えが面倒
  • エラーの場所がわからない

統合ターミナル

  • エディタの下に常にある
  • プロジェクトのルートで起動
  • キーボードだけで切り替え
  • エラーをクリックでジャンプ

コード編集とコマンド実行をシームレスに行き来できる

ターミナルプロファイル

シェルの選択

シェルmacOSWindows特徴
zshデフォルト-高機能、プラグイン豊富
bash利用可Git Bash標準的、サーバーでも同じ
fish要インストール-自動補完が優秀
PowerShell-デフォルトWindows標準

設定方法

"terminal.integrated.defaultProfile.osx": "zsh"

ターミナルの設定

// settings.json
{
  "terminal.integrated.fontSize": 14,
  "terminal.integrated.scrollback": 5000,
  "terminal.integrated.cursorStyle": "line",
  "terminal.integrated.fontFamily": "'Fira Code'",
  "terminal.integrated.copyOnSelection": true,
  "terminal.integrated.defaultProfile.osx": "zsh"
}

fontSize

ターミナルのフォントサイズ。エディタと別に設定可能。

scrollback

スクロールバック行数。デフォルト1000。大量ログには5000+推奨。

VS Code との連携

  • .venv がプロジェクト内にあると、VS Code が自動検出して Python インタープリタに設定

pip と requirements.txt

Terminal
# パッケージインストール
$ pip install requests flask numpy pandas
# 現在のパッケージを記録
$ pip freeze > requirements.txt
# 別の環境でパッケージを復元
$ pip install -r requirements.txt
# パッケージの確認
$ pip list

タスク (tasks.json)

よく使うコマンドをタスクに登録

// .vscode/tasks.json
{
  "version": "2.0.0",
  "tasks": [{
    "label": "Run Tests",
    "type": "shell",
    "command": "pytest tests/ -v",
    "group": "test"
  }]
}

Cmd+Shift+P → Tasks: Run Task でタスクを実行。毎回コマンドを入力しなくてよい。

演習3: 複数ターミナルの管理

1. Cmd+Shift+` でターミナルを3つ作成

2. それぞれのタブを右クリックして名前を付ける: 「server」「git」「test」

3. 「server」で python -m http.server 8000 を起動

4. 「git」タブに切り替えて git status を実行

5. 「test」タブで curl http://localhost:8000 を実行

ターミナル間を Cmd+Shift+[ / ] で切り替えて操作する
