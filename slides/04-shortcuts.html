ナビゲーション系 (1-3)

1. Cmd+Shift+P — コマンドパレット

VS Code の全機能にアクセス。迷ったらまずこれ。Session 3 で詳しく学んだ。

Cmd+Shift+P

2. Cmd+P — Quick Open

ファイル名のファジー検索。プロジェクト内のどこにあるファイルも即座に開く。

Cmd+P

3. Cmd+Shift+F — プロジェクト検索

プロジェクト全体から文字列を検索。関数の使用箇所を見つけるのに最適。

Cmd+Shift+F

4. Cmd+D — 次の一致を選択

1  const userName = "Alice";
2  console.log(userName);
3  const greeting = `Hello, ${userName}`;
4  sendEmail(userName);

使い方

  1. userName にカーソルを置く
  2. Cmd+D で1つ目を選択
  3. Cmd+D を連打で次の一致を追加
  4. 一括でリネーム入力

関連

Cmd+Shift+L — 全ての一致を一括選択
Cmd+K Cmd+D — 現在の選択をスキップして次へ

5. Cmd+/ — コメントトグル

Before

def calculate(x, y):
    result = x + y
    return result

After (Cmd+/ x3)

# def calculate(x, y):
# result = x + y
# return result

行を選択してから Cmd+/ でまとめてコメント化。もう一度押すと解除。
言語に応じてコメント記号が自動選択される（Python=#, JS=//, HTML=<!-- -->）

6. Alt+↑/↓ — 行を移動

Before

1  apple = "red"
2  banana = "yellow" ← カーソル
3  cherry = "red"

After (Alt+↑)

1  banana = "yellow" ← 上に移動!
2  apple = "red"
3  cherry = "red"

カット&ペーストなしで行を上下に移動。
複数行を選択してからも使える。コードの順序変更が一瞬。

UI操作系 (7-8)

7. Cmd+B — サイドバー切替

☰

サイドバーの表示/非表示を切り替え。
コーディング中はOFFにしてエディタ領域を広く使う。
ファイルを探すときだけONに。

8. Ctrl+` — ターミナル切替

⌨

統合ターミナルの表示/非表示。
コードを書く → ターミナルで実行 → 結果確認のループが爆速に。

この2つだけで「画面レイアウト」の操作は十分。

行操作系 (9-10)

9. Cmd+Shift+K — 行を削除

1  a = 1
2  debug_print(a) ← 削除!
3  b = a + 1

選択不要。カーソルがある行を丸ごと削除。

10. Shift+Alt+↓ — 行をコピー

1  item = create()
2  item = create() ← コピー!

現在の行を下に複製。テストケースの量産に便利。

選択・ジャンプ系 (11-12)

11. Cmd+L — 行を選択

現在の行を丸ごと選択。連続で押すと選択範囲が下に拡大。

複数行を選択してから Cmd+/ でまとめてコメント化、のように組み合わせる。

12. Cmd+Shift+\ — 対応括弧へジャンプ

ネストが深いコードで対応する括弧（{}, [], ()）に一発ジャンプ。

「この if 文の終わりはどこ?」が瞬時にわかる。

行操作の全体像

ショートカット動作補足

マルチカーソル実践

1  const items = [
2    {name: "apple", price: 100}|,
3    {name: "banana", price: 80}|,
4    {name: "cherry", price: 150}|,
5  ];

方法1: Cmd+D

} にカーソル → Cmd+D を連打 → 3つの } が選択 → 一括入力

方法2: Alt+Click

1行目でクリック → Alt を押しながら2行目、3行目をクリック → 3つのカーソル出現

方法3: 列選択

Cmd+Shift+Alt+↓ で下方向にカーソルを追加（矩形選択）

マルチウィンドウ操作

Cmd+Shift+N

新しいウィンドウを開く。複数プロジェクトを同時に開くときに使う。

VS Code のウィンドウ間を切り替え。

キーボードショートカット設定を開く。カスタマイズの入口。

Ctrl+Cmd+F

フルスクリーン切替。プレゼン時にも便利。
