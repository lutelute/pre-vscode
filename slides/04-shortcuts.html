行の移動: Alt+↑↓

行を上下に移動

カーソルがある行（or 選択した複数行）をそのまま上下に移動。
コピー&ペーストより圧倒的に速い。

Before

1 | def process():
2 | load_data()
3 | validate() ← カーソル
4 | transform()

After (Alt+↑)

1 | def process():
2 | validate() ← 移動した！
3 | load_data()
4 | transform()

行の複製: Shift+Alt+↓

行を瞬時にコピー

選択不要。カーソル行がそのまま下に複製される。
似たコードを書く時に非常に便利。

Before

print("name:", name)

After (Shift+Alt+↓)

print("name:", name)
print("name:", name) ← 編集

複製 → 変数名だけ変える、という流れが最速

行の削除: Cmd+Shift+K

行ごと消す

行を選択 → Delete ではなく、カーソルがある行を丸ごと削除。
複数行選択した状態なら、選択行を全て削除。

コメントトグル: Cmd+/

最も使うショートカットの一つ

カーソル行、または選択した複数行を一括コメント/アンコメント。
言語に応じて適切なコメント記号が使われる。

Python

# print("debug")
# x = calculate()

HTML

<!-- <div> -->

JavaScript

// const x = 42;

ブロックコメント: Shift+Alt+A （/* ... */ 形式）

HANDS-ON

各ショートカットを10回使おう（15分）

  1. Pythonファイルを開いて10行程度のコードを書く
  2. Alt+↑↓ で行を10回移動する
  3. Shift+Alt+↓ で行を5回複製する
  4. Cmd+Shift+K で不要な行を5回削除する
  5. Cmd+/ で行を10回コメント/アンコメントする
  6. Cmd+D で同じ単語を5回選択する
  7. Cmd+P でファイルを10回切り替える

キーバインドのカスタマイズ

変更方法

Cmd+K Cmd+S でキーバインド設定画面を開く

  • 検索バーでコマンド名を入力
  • 左のアイコンをクリックして新しいキーを入力
  • 「keybindings.json」でJSON直接編集も可能

キーマップ拡張

他のエディタから移行？ キーマップ拡張で慣れたキーバインドをそのまま使える。
Vim, Sublime Text, IntelliJ, Atom 等に対応。
