.vscode/ は Git にコミットしてチームで共有する

（ただし個人設定は除く）

.vscode/ で Git にコミットするもの/しないもの

ファイルGit にコミット理由
settings.jsonするチーム共通のフォーマッタ・リンター設定
launch.jsonするデバッグ設定をチームで統一
tasks.jsonするビルド・テストコマンドを共有
extensions.jsonする必須拡張をチームに推奨
個人的なパス設定しないマシン固有のパスは User 設定へ
*.code-snippets場合によるプロジェクト共通なら Git、個人用なら User

.gitignore の例: .vscode/* + !.vscode/settings.json + !.vscode/launch.json で選択的にコミット

extensions.json — 推奨拡張の共有

.vscode/extensions.json
{
  "recommendations": [
    "ms-python.python",
    "ms-python.debugpy",
    "charliermarsh.ruff",
    "ms-python.pylint",
    "eamodio.gitlens"
  ],
  "unwantedRecommendations": [
    "ms-vscode.vscode-typescript-tslint-plugin"

効果: プロジェクトを開くと「推奨拡張をインストールしますか?」と通知が出る。チーム全員が同じ拡張を使えるようになる。

スニペットの作り方

Cmd+Shift+P → "Snippets: Configure Snippets" → 言語を選択（例: Python）

Global / プロジェクト固有 / 言語固有から選べる

スニペット構文の基本

python.json (snippet file)
{
  "Python Main Block": {
    "prefix": "ifmain", // トリガー文字列
    "body": [
      "if __name__ == \"__main__\":",
      "    ${1:main()}" // $1 = 最初のTab位置
    ],
    "description": "if __name__ == '__main__' block"
  }
}
構文意味例
$1, $2, $3...Tab ストップ（入力位置）Tab で順番に移動
$0最終カーソル位置全てのTab入力後の位置
${1:default}デフォルト値付き${1:name}
${1|one,two,three|}選択肢ドロップダウンから選択

スニペット変数

変数展開結果使いどころ
$TM_FILENAME現在のファイル名ヘッダーコメント
$TM_FILENAME_BASE拡張子なしファイル名クラス名・モジュール名
$TM_DIRECTORYディレクトリパスパス参照
$CURRENT_YEAR現在の年Copyright年
$CURRENT_MONTH現在の月日付
$CURRENT_DATE現在の日日付
$CLIPBOARDクリップボード内容ペースト+テンプレート
$UUIDランダムUUID一意ID生成

Emmet — HTML をワンタッチで展開

入力 (Emmet 略記)展開結果
div.container>h1+p*3div.container の中に h1 と p が3つ
ul>li.item*5ul の中に li.item が5つ
input:email<input type="email">
link:css<link rel="stylesheet" href="style.css">
! (HTML5)HTML5 テンプレート全体
table>tr*3>td*43行4列のテーブル

使い方: 略記を入力 → Tab で展開。HTML/CSS ファイルで自動有効。
設定: "emmet.includeLanguages": {"javascript": "html"} で他の言語でもEmmet有効。

tasks.json — タスクの自動化

tasks.json
タスク定義
→
Cmd+Shift+B
ビルドタスク実行
→
Terminal
結果を表示
→
Problems
エラーを検出

何が嬉しいのか

  • 毎回ターミナルでコマンドを打たなくていい
  • ショートカット1つでテスト・リント・ビルドを実行
  • エラー出力を Problems パネルに自動表示
  • チームメンバーと同じタスクを共有

tasks.json の基本構造

.vscode/tasks.json
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "pytest", // タスク名
      "type": "shell", // shell or process
      "command": "python -m pytest tests/ -v",
      "group": {
        "kind": "test",
        "isDefault": true
      },
      "presentation": { "reveal": "always" }
    }
  ]
}

タスクの実例

pytest

"label": "Run Tests",
"type": "shell",
"command": "python -m pytest -v",
"group": "test"

ruff check

"label": "Lint",
"type": "shell",
"command": "ruff check .",
"problemMatcher": []

ruff format

"label": "Format",
"type": "shell",
"command": "ruff format .",
"group": "build"

実行方法: Cmd+Shift+P → "Tasks: Run Task" → タスク選択
ショートカット: Cmd+Shift+B でデフォルトビルドタスクを実行

Problem Matcher — エラーを自動検出

Terminal 出力

src/main.py:23:5: E302 expected 2 blank
 lines before function
src/utils.py:45:1: F401 'os' imported
 but unused

Problems パネル

E302 main.py:23 — expected 2 blank lines
F401 utils.py:45 — 'os' imported but unused

クリックで該当行にジャンプ!

組み込みマッチャー: "problemMatcher": "$eslint-stylish", "$tsc", "$gcc" など。Pythonは []（なし）で OK。

複合タスク (Compound Tasks)

tasks.json
{
  "label": "Check All",
  "dependsOn": ["Lint", "Run Tests", "Format"],
  "dependsOrder": "sequence", // 順番に実行
  "group": {
    "kind": "build",
    "isDefault": true
  }
}

sequence

Lint → Tests → Format の順番で実行。前が失敗しても次に進む。

parallel

全タスクを同時実行。サーバー+クライアントの同時起動などに。

タスクの実行方法

方法ショートカット説明
Run TaskCmd+Shift+P → "Run Task"全タスク一覧から選択
Build TaskCmd+Shift+Bデフォルトビルドタスクを実行
Test TaskCmd+Shift+P → "Run Test Task"デフォルトテストタスクを実行
Rerun LastCmd+Shift+P → "Rerun Last Task"直前のタスクを再実行
Terminal からターミナルで直接入力一回限りのコマンド

Tips: よく使うタスクにはキーバインドを割り当てよう。
keybindings.json で "command": "workbench.action.tasks.runTask" + "args": "Run Tests"

ワークスペーススニペット

グローバル vs ワークスペース

種類保存先適用範囲
Global~/Library/.../snippets/全プロジェクト
Workspace.vscode/*.code-snippetsプロジェクト内

プロジェクト専用スニペット

Cmd+Shift+P → "Snippets: Configure Snippets" → "New Snippets file for 'project'..."

プロジェクト固有のテンプレートをチームで共有。Git にコミット可能。

Workspace Trust — セキュリティ機能

信頼されたワークスペース

  • 全ての拡張機能が有効
  • tasks.json のコマンド実行可能
  • launch.json のデバッグ可能
  • 全ての設定が反映される

制限モード

  • 一部の拡張機能が無効
  • タスク実行が制限される
  • デバッグが制限される
  • 悪意あるコードからの保護

不明なリポジトリを開いた時の安全装置。自分のプロジェクトなら「Trust」を選択。

Python スニペットを作る

演習2: タスクを定義

HANDS-ON (15分)

tasks.json を作成

  1. .vscode/tasks.json を作成（またはCmd+Shift+P → "Configure Task"）
  2. pytest タスクを追加: "command": "python -m pytest -v"
  3. ruff check タスクを追加: "command": "ruff check ."
  4. 両方を実行する複合タスク "Check All" を作成
  5. Cmd+Shift+B で実行テスト

extensions.json を作成

  1. .vscode/extensions.json を作成
  2. Python 開発に必要な拡張を recommendations に追加
  3. ファイルを保存して効果を確認
