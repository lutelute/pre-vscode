Source Control パネル

Ctrl+Shift+G で開く

Activity Bar の Git アイコン、またはショートカットで Source Control ビューを表示。

表示される情報

  • Changes — 変更されたファイル一覧
  • Staged Changes — ステージ済み（コミット対象）
  • ファイル横のアイコン — M(変更), U(未追跡), D(削除), A(追加)
  • diff ビュー — ファイルをクリックすると差分表示

Gutter Indicators

エディタ左端のGit表示

緑の線

新しく追加された行

青の線

変更された行

赤の三角

削除された行

ガターの色マーカーをクリックすると、変更前との差分を inline で表示

GUIでの操作

  1. ファイルを編集
  2. Source Control で変更ファイルの + をクリック（Stage）
  3. コミットメッセージを入力 → ✓ ボタン（Commit）
  4. … メニュー → Push（GitHub に送信）

ブランチ操作

ステータスバーからブランチ操作

左下のブランチ名をクリック → ブランチ作成・切替

よく使う操作

操作方法
新規ブランチ作成ステータスバー → "Create new branch"
ブランチ切替ステータスバー → ブランチ名を選択
ブランチ削除コマンドパレット → "Git: Delete Branch"
マージコマンドパレット → "Git: Merge Branch"

GitLens 拡張

行ごとの blame 表示

各行の右端に「誰が・いつ・なぜ変更したか」が薄く表示される。
クリックすると詳細なコミット情報が見られる。

主な機能

  • Current Line Blame — カーソル行のコミット情報
  • File History — ファイルの変更履歴
  • Commit Graph — ブランチ・マージの視覚化
  • Stash Explorer — stash の管理

Merge Conflict の解消

コンフリクト発生時

VS Code がコンフリクト箇所を色分け表示。上部にボタンが表示される。

<<<<<<< HEAD (Current Change)
result = calculate_v2(data)
=======
result = calculate(data, method="new")
>>>>>>> feature-branch (Incoming Change)

解消ボタン

  • Accept Current — 自分の変更を採用
  • Accept Incoming — 相手の変更を採用
  • Accept Both — 両方を残す
  • Compare — 並べて比較

練習タイム

HANDS-ON

Git操作演習（15分）

  1. git init でリポジトリ初期化
  2. ファイルを作成・編集
  3. Source Controlパネルで Stage → Commit
  4. ステータスバーからブランチ作成
  5. 新ブランチで編集 → Commit
  6. main に戻って別の編集 → Commit
  7. マージを試みる（コンフリクトが起きたら解消）

diff 表示が強力

ガターの色マーカー、inline diff、side-by-side diff。

GitLens で履歴を読む

「誰がいつ何を変えた」が一目でわかる。
