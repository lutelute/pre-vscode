ファイル内検索: Cmd+F

基本操作

操作macOSWin/Linux
検索を開くCmd+FCtrl+F
次のマッチへEnter or Cmd+GEnter or F3
前のマッチへShift+EnterShift+F3
検索を閉じるEscEsc

検索オプション（アイコン）

  • Aa — 大文字/小文字を区別
  • ab — 単語単位でマッチ
  • .* — 正規表現を使用

ファイル内置換: Cmd+H

基本操作

Cmd+H（Ctrl+H）で検索+置換フィールドが開く

  • 1つずつ置換: 置換ボタン (or Cmd+Shift+1)
  • 全て置換: 全置換ボタン (or Cmd+Alt+Enter)

保持される設定

大文字小文字の区別、正規表現などの設定は検索ウィジェットを閉じても保持される。

プロジェクト全体検索: Cmd+Shift+F

サイドバーの Search ビュー

プロジェクト内の全ファイルを横断検索。マッチした行がファイルごとにグループ化表示。

フィルタ機能

  • files to include: *.py src/** — 検索対象を限定
  • files to exclude: node_modules *.log — 除外
  • 否定パターン: !tests/ で tests フォルダを除外

プロジェクト全体置換: Cmd+Shift+H

注意: 全ファイルに影響

プロジェクト全体の置換は強力だが危険。必ず変更内容をプレビューしてから実行。

安全に使うコツ

  1. まず Cmd+Shift+F で検索結果を確認
  2. フィルタで対象ファイルを絞る
  3. Gitでコミットしてから実行（元に戻せるように）
  4. 1ファイルずつ確認しながら置換

正規表現の基本

パターン意味例
.任意の1文字a.c → abc, a1c
*直前の0回以上ab*c → ac, abc, abbc
+直前の1回以上ab+c → abc, abbc
\d数字\d+ → 42, 100
\w英数字+_\w+ → hello, x_1
()キャプチャグループ(\w+)=(\w+)
$1置換でグループ参照$2=$1 で入替

正規表現の実践例

例1: print文を logging に変換

検索: print\((.+?)\)
置換: logger.info($1)

例2: 日付フォーマット変換

検索: (\d{4})/(\d{2})/(\d{2})
置換: $1-$2-$3
結果: 2024/01/15 → 2024-01-15

例3: 変数名のスタイル変換

検索: ([a-z])([A-Z])
置換: $1_\l$2 (VS Code は \l 未対応。拡張機能で対応可能)

定義ジャンプ

操作macOS説明
定義へジャンプF12関数/クラスの定義元に飛ぶ
Peek DefinitionAlt+F12インラインで定義をプレビュー
参照を検索Shift+F12この関数がどこで使われているか
型定義へジャンプCmd+ClickCmd押しながらクリック
前の位置に戻るCtrl+-ジャンプ前に戻る

F12 と Ctrl+- のセットを覚えると、コードリーディングが劇的に速くなる

練習タイム

HANDS-ON

検索・置換演習（15分）

  1. Pythonファイルで Cmd+F → 関数名を検索
  2. Cmd+H で変数名を一括置換
  3. Cmd+Shift+F でプロジェクト全体検索（フィルタ: *.py）
  4. 正規表現モードON → \d+ で数値を検索
  5. print\((.+?)\) → logger.info($1) で置換を試す
  6. F12 で定義ジャンプ → Ctrl+- で戻る

まとめ

3段階の検索

Cmd+F（ファイル内）→ Cmd+Shift+F（プロジェクト）→ F12（定義ジャンプ）

正規表現で複雑な置換

キャプチャグループ () と $1 で柔軟な変換。

フィルタで安全に

全体置換は必ずフィルタを使い、Git コミット後に実行。
