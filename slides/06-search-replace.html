正規表現の基礎

パターン意味マッチ例
.任意の1文字a.c → abc, a1c, a-c
*直前の文字を0回以上ab*c → ac, abc, abbc
+直前の文字を1回以上ab+c → abc, abbc (acは不可)
?直前の文字を0回か1回colou?r → color, colour
\d数字 [0-9]\d{3} → 123, 456
\w英数字+アンダースコア\w+ → hello, var_1
\s空白文字スペース、タブ、改行
()グループ化（キャプチャ）(\w+)@(\w+)
$1, $2キャプチャグループの参照置換文字列で使用
^ / $行頭 / 行末^# → コメント行

正規表現 実例1: print を logger に変換

Before

print("Start processing")
print("User: " + name)
print(f"Result: {result}")

After

logger.info("Start processing")
logger.info("User: " + name)
logger.info(f"Result: {result}")

検索: print\((.+)\)

置換: logger.info($1)

(.+) で引数をキャプチャし、$1 で参照

正規表現 実例2: 日付フォーマット変換

Before (YYYY-MM-DD)

2024-01-15
2024-03-22
2024-12-01

After (MM/DD/YYYY)

01/15/2024
03/22/2024
12/01/2024

検索: (\d{4})-(\d{2})-(\d{2})

置換: $2/$3/$1

$1=年, $2=月, $3=日。並び替えるだけ

正規表現 実例3: snake_case → camelCase

Before (snake_case)

user_name
first_login_date
max_retry_count

After (camelCase)

userName
firstLoginDate
maxRetryCount

検索: _([a-z])

置換: ${1:/upcase}

VS Code独自の変換構文: /upcase で大文字に変換（複数回実行が必要な場合あり）

タスク: print を logging に変換

1. 任意のPythonファイルを開く

2. Cmd+H で置換ダイアログを開く

3. 正規表現モード (.*) をON

4. 検索: print\((.+)\)

5. 置換: logging.info($1)

6. 1つずつ確認しながら置換、または全て置換

演習2: プロジェクト全体検索

タスク: TODO コメントを探す

1. Cmd+Shift+F でSearch パネルを開く

2. TODO と入力

3. 「files to include」に *.py と入力

4. 「files to exclude」に **/venv/**,**/__pycache__/** と入力

5. 結果をクリックして各TODOの場所を確認

発展: 正規表現で TODO/FIXME/HACK を一括検索

検索: (TODO|FIXME|HACK):?\s*(.*)

正規表現モードをONにすること

演習3: コードナビゲーション

タスク: 関数の定義と参照を追う

1. 任意のPythonプロジェクトを開く

2. 関数呼び出しにカーソルを置いて F12 — 定義にジャンプ

3. Ctrl+- で元の場所に戻る

4. 同じ関数で Alt+F12 — Peek Definitionで確認

5. Esc で Peek を閉じる

6. Shift+F12 — 全参照箇所を一覧表示

検索のプロTips

選択してから検索

テキストを選択して Cmd+F すると、検索欄に自動入力される

選択範囲内で検索

Cmd+F後に「選択範囲内で検索」アイコンをON

検索履歴

検索欄で ↑↓ キーを押すと過去の検索を呼び出せる

大文字小文字を保持

置換時「AB」アイコンをONにすると元の大文字小文字パターンを保持

Cmd+F → Cmd+Shift+F

検索中に Cmd+Shift+F でプロジェクト全体検索に切り替え可能

結果パネルの活用

検索結果を右クリックで「全てコピー」や「除外」ができる
