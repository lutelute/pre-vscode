VS Code とは？

📝

コードエディタ

Microsoftが開発する無料・オープンソースのコードエディタ。2015年リリース以来、最も人気のエディタに成長。

🌍

クロスプラットフォーム

macOS / Windows / Linux で同じ体験。設定も同期可能。

Stack Overflow Developer Survey で73%以上の開発者が使用（2024年）

VS Code の4つの特徴

🪶

軽量・高速

Electron製だが起動が速い。大きなファイルも快適に編集。

🧩

拡張性

5万以上の拡張機能。Python, Git, SSH, AI…何でも追加可能。

🔓

オープンソース

GitHubで公開。コミュニティが活発に開発・改善。

🤖

AI統合

GitHub Copilot など最新のAIツールが統合可能。

エディタ比較：VS Code vs 他のツール

エディタ種類長所短所
VS Codeエディタ軽量・拡張豊富・無料初期設定が必要

なぜ PWS Lab で VS Code？

  • Remote-SSH で研究室サーバー (pws-160core, pws-gpu) に直接接続
  • Python拡張 が充実（Pylance, Ruff, Jupyter, Debugger）
  • Git統合 でバージョン管理がGUIで完結
  • 統合ターミナル でエディタ内からコマンド実行
  • GitHub Copilot が学生は無料で使える
  • 設定同期 で自宅PCとラボPCで同じ環境

IDE とエディタの違い

IDE（統合開発環境）

  • 全機能が最初から入っている
  • 例: PyCharm, IntelliJ, Xcode
  • 設定不要ですぐ使える
  • 重い・メモリ消費大
  • 言語ごとに別ツール

エディタ + 拡張

  • 必要な機能だけ追加する
  • 例: VS Code, Vim, Sublime
  • 初期設定が必要
  • 軽い・カスタマイズ自在
  • どの言語でも1つのツール

VS Code は「拡張で IDE 並みになるエディタ」という立ち位置

Terminal — zsh

Homebrew が入っていない場合: /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

インストール：Linux

Terminal — bash
# Ubuntu / Debian: snap（推奨）
$ sudo snap install code --classic
# または apt
$ sudo apt update && sudo apt install code
# Fedora / RHEL
$ sudo dnf install code
# インストール確認
$ code --version
1.96.2

インストール：Windows

PowerShell
# 方法1: winget（推奨）
PS> winget install Microsoft.VisualStudioCode
# 方法2: 公式サイトからインストーラー
https://code.visualstudio.com/download
# ※「PATHに追加」を必ずチェック！
☑ Add to PATH (available after restart)

code コマンドの設定

インストール
→初回起動
→日本語化
→code コマンド
Terminal
# macOS: コマンドパレットから設定
Cmd+Shift+P → "Shell Command: Install 'code' command in PATH"
# 使い方
$ code . # 現在のフォルダを開く
$ code file.py # ファイルを開く
$ code -d a.py b.py # 2ファイルのdiffを表示
$ code --install-extension ms-python.python

重要: code . はこの講座で最も使うコマンドです！

code . が重要な理由

ファイル単体を開く

  • ファイルツリーが見えない
  • 検索がそのファイルだけ
  • Git連携が効かない
  • 拡張機能の動作が不完全

フォルダごと開く ✓

  • プロジェクト全体が見える
  • 全ファイル横断検索
  • Git差分が表示される
  • 全拡張機能がフル機能動作

ターミナルでプロジェクトフォルダに移動 → code . が基本の流れ

設定の同期 (Settings Sync)

Settings Sync とは

GitHubアカウントでログインすると、設定・拡張機能・テーマなどがクラウド同期される。

有効化する方法

  1. 左下の歯車アイコン → 設定の同期をオンにする
  2. GitHub アカウントでサインイン
  3. 同期する項目を選択（全てONで OK）

これで何が便利？

自宅のMac、大学のPC、サーバー接続…
どこでも同じ設定・テーマ・拡張機能で作業できる。

まとめ

VS Code = 無料・軽量・拡張性抜群のエディタ

世界で最も人気のコードエディタ。研究室の開発に最適。

インストールは簡単

brew / snap / winget で1コマンド。code コマンドをPATHに追加。

Settings Sync で環境統一
