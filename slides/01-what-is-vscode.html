VS Code vs Vim — 詳細比較

VS Code

  • GUIベース、マウスも使える
  • すぐに使い始められる
  • 統合ターミナル・Git・デバッガ内蔵
  • 拡張機能はクリックでインストール
  • Remote SSHでサーバーも操作可能

向いている人: 初心者〜中級者、チーム開発

Vim / Neovim

  • 完全キーボード操作（モーダル編集）
  • 学習曲線が急（最初の1週間が辛い）
  • SSHだけで使える（GUIなし環境で必須）
  • 設定は .vimrc をテキストで書く
  • 使いこなすと最速の編集速度

向いている人: サーバー管理者、上級エンジニア

Tip: VS Codeの Vim 拡張で両方のいいとこ取りも可能

VS Code vs Cursor

VS Code

  • 本家。安定性と互換性が最高

VS Code の歴史と設計思想

2015年: 初リリース

MicrosoftがBuild 2015で発表。当時はIDEの時代だったが、「軽量だが強力な」エディタとして登場。

技術スタック: Electron + Monaco Editor

Electron: Chromium + Node.js のフレームワーク。Web技術でデスクトップアプリを作成。
Monaco Editor: VS Codeのエディタ部分。ブラウザでも動作する高性能エディタ。

Language Server Protocol (LSP)

VS Codeが生んだ革命的プロトコル。言語サポートをエディタから分離し、一度作れば全エディタで使える仕組み。

オープンソース戦略

MicrosoftがGitHub（2018年買収）と連携し、開発者コミュニティの中心に。月間アクティブユーザー1500万人以上。

最初にやるべき設定

Cmd+, で Settings を開く

Auto Save

files.autoSave: "afterDelay"

保存忘れゼロ。Ctrl+Sから解放。

Format On Save

editor.formatOnSave: true

保存時に自動フォーマット。コードが常に綺麗。

Font Size

editor.fontSize: 14

12-16の間で見やすいサイズに。

Tab Size

editor.tabSize: 4

Pythonは4、JSは2が一般的。

Word Wrap

editor.wordWrap: "on"

長い行を折り返して表示。

Minimap

editor.minimap.enabled: false

小さい画面では非表示にして領域確保。

settings.json に直接書く

Cmd+Shift+P → "Preferences: Open User Settings (JSON)"

settings.json
{
  "files.autoSave": "afterDelay",
  "editor.formatOnSave": true,
  "editor.fontSize": 14,
  "editor.tabSize": 4,
  "editor.wordWrap": "on",
  "editor.minimap.enabled": false,
  "editor.renderWhitespace": "boundary",
  "editor.bracketPairColorization.enabled": true,
  "workbench.startupEditor": "none"
}

GUI設定 と JSON設定 は同じものの別の表示。JSONの方が正確でコピペ可能。

最初に入れるべき拡張機能

Python (Microsoft)

IntelliSense、リンティング、デバッグ、Jupyter対応。Pythonユーザー必須。

Pylance

高速な型チェックと補完。Python拡張と一緒に入る。

GitLens

Git blame、履歴表示、差分ビューが超強化される。

Prettier

HTML/CSS/JS/JSON の自動フォーマット。formatOnSave と組み合わせて使う。

Error Lens

エラー・警告をインラインで表示。問題の発見が爆速に。

Remote - SSH

リモートサーバーに接続してローカルと同じ体験で開発。
