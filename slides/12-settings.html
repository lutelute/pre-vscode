User Settings vs Workspace Settings

User Settings（全体）

  • 全プロジェクトに適用
  • Cmd+, で開く
  • ファイル: ~/Library/Application Support/Code/User/settings.json

Workspace Settings（プロジェクト）

  • そのフォルダだけに適用
  • User Settings より優先
  • ファイル: .vscode/settings.json
  • Gitに含めてチームで共有可能

優先順位: Workspace > User > Default

推奨 settings.json

settings.json
{
  // 自動保存
  "files.autoSave": "afterDelay",
  "files.autoSaveDelay": 1000,
  // 保存時フォーマット
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "charliermarsh.ruff",
  // フォント
  "editor.fontSize": 14,
  "editor.fontFamily": "'Fira Code', Menlo, monospace",
  "editor.fontLigatures": true,
  // エディタ
  "editor.guides.bracketPairs": true,
  "editor.bracketPairColorization.enabled": true,
  "files.trimTrailingWhitespace": true,
  "files.insertFinalNewline": true
}

設定カスタマイズ演習（15分）

  1. Cmd+Shift+P → "Open Settings (JSON)" で settings.json を開く
  2. 推奨設定（autoSave, formatOnSave, fontSize等）を追加
  3. Fira Code フォントをインストールして設定
  4. テーマを3つ試して好みのものに決定
  5. Cmd+K Cmd+S でキーバインド画面を確認

まとめ

settings.json で全てを制御

GUIでもJSONでも設定可能。autoSave と formatOnSave は必須。

User vs Workspace の使い分け

個人設定は User、プロジェクト設定は .vscode/ に。

見た目にもこだわる

テーマとフォントで長時間作業の疲れを軽減。
