GUI Settings vs settings.json

GUI Settings

Cmd+,（Mac）/ Ctrl+,（Win/Linux）

  • 検索バーで設定を探せる
  • 説明付きで直感的
  • チェックボックス・ドロップダウン
  • 変更されたものにマーク表示
  • 初心者におすすめ

settings.json

Cmd+Shift+P → "Preferences: Open Settings (JSON)"

  • 全設定を一覧で確認
  • コピペで設定を共有できる
  • 一括編集・バックアップが楽
  • GUIにない設定もある
  • 慣れると圧倒的に速い

GUIで変更 = settings.json に自動反映。どちらで変えても同じ結果。

おすすめ設定 (settings.json)

settings.json
{
  "files.autoSave": "afterDelay", // 自動保存
  "files.autoSaveDelay": 1000, // 1秒後
  "editor.formatOnSave": true, // 保存時フォーマット
  "editor.fontSize": 14,
  "editor.tabSize": 4,
  "editor.wordWrap": "on", // 折り返し
  "editor.minimap.enabled": false, // ミニマップ非表示
  "editor.bracketPairColorization.enabled": true,
  "editor.guides.bracketPairs": true, // 括弧ガイド
  "files.trimTrailingWhitespace": true, // 末尾空白削除
  "files.insertFinalNewline": true, // 最終行に改行
}

Python 開発者向け設定

settings.json (Python)
{
  "python.defaultInterpreterPath": "./venv/bin/python",
  "[python]": {
    "editor.defaultFormatter": "charliermarsh.ruff",
    "editor.formatOnSave": true,
    "editor.codeActionsOnSave": {
      "source.organizeImports": "explicit"
    }
  },
  "python.analysis.typeCheckingMode": "basic",
  "python.testing.pytestEnabled": true,
  "python.testing.pytestArgs": ["tests"]
}

[python] ブロック内の設定はPythonファイルにのみ適用される（言語固有設定）

ミニマップの設定

ミニマップとは

エディタ右端に表示されるコードのプレビュー。長いファイルの全体像が見える。

// 非表示にする場合
"editor.minimap.enabled": false

// カスタマイズ
"editor.minimap.maxColumn": 80,
"editor.minimap.renderCharacters": false,
"editor.minimap.scale": 2

ミニマップ: ON vs OFF

ON にする理由OFF にする理由
長いファイルで全体把握画面が狭くなる
現在位置がわかるノートPCでは邪魔
クリックで素早く移動使わない人も多い

個人の好み。迷ったらOFFで画面を広く使おう。

キーバインドのカスタマイズ

Cmd+K Cmd+S (Mac) / Ctrl+K Ctrl+S (Win/Linux)

キーボードショートカット一覧が開く。検索して変更可能。

keybindings.json
[
  {
    "key": "cmd+shift+d",
    "command": "editor.action.duplicateSelection",
    "when": "editorTextFocus"
  },
  {
    "key": "cmd+k cmd+c", // コードキー
    "command": "workbench.action.terminal.clear"
  }
]

キーバインドの "when" 条件

when 条件意味例
editorTextFocusエディタにフォーカス中テキスト編集時のみ有効
terminalFocusターミナルにフォーカス中ターミナル操作時のみ
inDebugModeデバッグ実行中デバッグ時の特別なキー
editorLangId == 'python'Pythonファイル編集中言語固有のショートカット
!editorReadonly読み取り専用でない編集可能な時のみ
sideBarVisibleサイドバー表示中サイドバー関連操作

組み合わせ: "when": "editorTextFocus && editorLangId == 'python'"
Python ファイルでエディタにフォーカスがある時のみ有効

"workbench.colorCustomizations": {
  "titleBar.activeBackground": "#1a1a2e", // タイトルバー
  "statusBar.background": "#0a3d62", // ステータスバー
  "statusBar.debuggingBackground": "#8B0000", // デバッグ中
  "tab.activeBackground": "#1a1a2e", // アクティブタブ
  "editor.selectionBackground": "#264f78" // 選択範囲
}

プロジェクト別にステータスバーの色を変える

Workspace settings に設定すれば、プロジェクトごとにステータスバーの色を変えられる。「今どのプロジェクトを開いているか」一目瞭然。

シンタックスハイライトのカスタマイズ

settings.json
"editor.tokenColorCustomizations": {
  "textMateRules": [
    {
      "scope": "comment",
      "settings": {
        "foreground": "#6A9955",
        "fontStyle": "italic"
      }
    }
  ]
}

scope の確認方法: Cmd+Shift+P → "Developer: Inspect Editor Tokens and Scopes" で任意のトークンのスコープ名を確認できる。

autoSave の4つのモード

モード動作設定値
off手動保存のみ（Cmd+S）"off"
afterDelay指定ミリ秒後に自動保存"afterDelay" + autoSaveDelay: 1000
onFocusChange他のファイルに切り替えた時"onFocusChange"
onWindowChangeVS Code からフォーカスが離れた時"onWindowChange"

おすすめ

"afterDelay" (1000ms) が一般的。formatOnSave と併用すると、1秒後に自動フォーマット＆保存される。

注意: Git で差分が大量に出る場合は "onFocusChange" に変更を検討。

ターミナルの設定

settings.json (Terminal)
{
  "terminal.integrated.fontFamily": "'Fira Code', monospace",
  "terminal.integrated.fontSize": 13,
  "terminal.integrated.defaultProfile.osx": "zsh",
  "terminal.integrated.scrollback": 5000,

演習1: settings.json をカスタマイズ

HANDS-ON (15分)

Step 1: settings.json を開く

  1. Cmd+Shift+P → "Open User Settings (JSON)"
  2. 以下を追加:
"files.autoSave": "afterDelay",
"editor.formatOnSave": true,
"editor.fontSize": 14,
"files.trimTrailingWhitespace": true,
"files.insertFinalNewline": true

Step 2: テーマを変更

  1. Cmd+K Cmd+T でテーマ選択
  2. 好みのテーマを選択
  3. 上下キーでプレビュー確認
  4. Enterで確定

Step 3: フォント

  1. Fira Code をインストール
  2. settings.json でフォント設定
  3. リガチャを有効化

演習2: Workspace設定とプロファイル

HANDS-ON (10分)

Workspace 設定を試す

  1. プロジェクトフォルダを開く
  2. Cmd+Shift+P → "Open Workspace Settings (JSON)"
  3. .vscode/settings.json に Python 設定を追加
  4. ステータスバーの色を変えてみる:
"workbench.colorCustomizations": {
  "statusBar.background": "#005f00"
}

プロファイルを作成

  1. Cmd+Shift+P → "Profiles: Create Profile"
  2. 名前を付ける（例: "Python Dev"）
  3. 現在の設定をベースにする
  4. "Profiles: Switch Profile" で切替を試す
